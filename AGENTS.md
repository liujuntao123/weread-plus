# weread-plus

`weread-plus` 是一款基于 **Tauri 2** 构建的微信读书桌面增强客户端。通过双栏分屏架构（左侧内嵌微信读书原生 Web 视窗、右侧宿主定制化辅助工作区），实现章节导读大纲、双向联动定位、划线笔记聚合检索以及上下文感知的 AI 智能伴读。

## Agent skills

### Issue tracker

Work is tracked locally as markdown files in `.scratch/weread-plus/issues/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical triage roles mapped to five default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout with root `CONTEXT.md` and architecture decisions in `docs/adr/`. See `docs/agents/domain.md`.
