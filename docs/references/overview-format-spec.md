# Overview Hub 导读文档格式与对齐规范

> Overview Hub 是 `weread-plus` 中用于展示全书知识骨架的核心资产。用户可手动导入个人编写的 Markdown 导读，或由 AI 自动生成。本规范定义了导读文档的 FrontMatter、标题层级、要点提炼语法以及与原书目录的对齐策略。

---

## 1. 结构与层级规则

导读文档必须采用标准 GitHub Flavored Markdown (GFM) 格式：

1. **顶级标题 (`#`)**：全书总览与书名（一篇文档仅允许一个 `#`）。
2. **二级标题 (`##`)**：对应书籍的 **篇/卷/部分 (Part)** 或 **主要章 (Chapter)**。
3. **三级标题 (`###`)**：对应具体的 **节 (Section)**。
4. **四级标题 (`####`)**：对应节内的 **核心要点小结**（可选）。

---

## 2. FrontMatter 元数据标准

导读文档头部支持 YAML FrontMatter，声明与原书的强绑定关系：

```yaml
---
bookId: "3300045871"           # 对应微信读书唯一的 bookId（推荐提供）
title: "思考，快与慢"           # 书籍中文全称
author: "丹尼尔·卡尼曼"          # 原书作者
version: "1.0.0"               # 导读版本
tags: ["心理学", "认知偏差", "行为经济学"]
source: "人工撰写"             # 来源标识："人工撰写" | "AI 生成" | "外部导入"
updatedAt: "2026-09-18"
---
```

## 3. 语义化卡片标记语法

为了使侧边栏的渲染更加丰富直观，Overview Hub 规范支持扩展的标准 Markdown 引用与列表约定：

### 3.1 核心论点提炼（Core Proposition）
使用无序列表 `-` 配合加粗起始短语表达论点：
```markdown
- **双系统运作模型**：人类思考由无意识直觉（系统1）与理性深思（系统2）协同驱动。
- **精力损耗效应**：长时间使用系统2将导致自我损耗，促使大脑退回系统1的省力模式。
```

### 3.2 原书经典金句（Quotes & Anchors）
使用带前缀的引用块，系统将自动识别并渲染为高光金句卡片：
```markdown
> [!QUOTE]
> “我们对某一事物的直觉反应，往往源自对另一个更简单问题的偷换回答。”
```

### 3.3 批判性思考与思维陷阱（Pitfalls / Caveats）
使用警告类型的引用块：
```markdown
> [!WARNING] 常见思维陷阱
> 小数定律（Law of Small Numbers）：人们常常过分相信小样本能够反映总体真实特征。
```

## 4. 章节智能对齐与映射逻辑

解析器读取 Markdown AST 后，执行如下步骤建立与微信读书目录的映射：

```
+------------------------------------+
|  Markdown AST Heading (二级/三级标题) |
+------------------------------------+
                  │
                  ▼
   [ 正则清理与序号归一化 ]
   - 去除 "第/卷/章/节/回"、中英文标点、两端空格
   - 提取序号数字 (一 -> 1, 01 -> 1)
                  │
                  ▼
+------------------------------------+
|  WeRead 原生目录 ChapterInfo 列表  |
+------------------------------------+
                  │
        ┌─────────┴─────────┐
        ▼                   ▼
  【完全匹配】            【模糊距离比对】
  (CleanTitle相等)      (Levenshtein Similarity >= 0.82)
        │                   │
        └─────────┬─────────┘
                  ▼
    生成确定的 chapterUid 映射绑定
```

若某节点匹配失败，系统会将该节点标记为 `unmapped`，用户可在侧边栏界面点击“关联原书章节”，手动指定原书对应目录。
